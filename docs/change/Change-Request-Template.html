Change Request Template

Use this template for any change to an approved baseline. No significant addition or removal may be made through an informal process. Complete every section in order; a request may not proceed past a stage until the previous stage is signed off (SEN381 Teaching Team, 2026a).

  7. Baseline Update
How this template is used

This form captures stages 1 and 2 only. Stages 3 to 7 are recorded by the team on the produced request during review.

Link requests folder points the page at docs/change/requests/. The page then reads pending-review/, approved/ and denied/, takes the highest CR number filed in any of them, and sets this request one step on from it. A browser cannot read a folder it has not been given, so this grant is needed once; it is remembered afterwards. Produce request writes the completed request into pending-review/ and clears the form. Once the team has reached a decision, the file is moved manually into approved/ or denied/.
