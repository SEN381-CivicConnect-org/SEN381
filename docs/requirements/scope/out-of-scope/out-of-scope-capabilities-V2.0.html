2.3 Out-of-Scope Capabilities v2.0

Baseline Version: 2.0 (Milestone 4 Final Delivery) | Scope Boundary & Architectural Exclusions

Deliberate Architectural Boundary

To deliver a hardened, production-ready, and verifiable system within an academic team boundary (3 students, 4 milestones, low-cost budget ≤ $25/mo), the project deliberately excluded non-essential features that introduce unbounded complexity or third-party carrier risk.

1. Excluded Capabilities & Engineering Rationale

Excluded Capability Rationale & Architectural Alternative
Native Mobile Apps (iOS / Android) Native app stores introduce SDK drift, mobile review delays, and platform-specific code duplication. CivicConnect utilizes a responsive, mobile-first Blazor Web App accessible via standard mobile browsers.
WhatsApp / Social Messaging Intake The core business problem was request fragmentation across uncontrolled channels. Adding WhatsApp intake would exacerbate fragmentation and expose the system to Meta API licensing and webhook failure modes.
Automated AI / LLM Triage Non-deterministic LLM classifiers can hallucinate urgency or misroute emergencies. The system enforces a transparent, deterministic mathematical matrix (PriorityMatrix.cs) with human supervisor override authority.
Multi-Tenant Enterprise SaaS Hosting multiple municipal organizations in a single shared database instance introduces severe POPIA co-mingling risks and cross-tenant data leaks. The stack is designed for single-organization deployment per container stack.
Payment & Billing Processing Financial billing and gateway integrations (e.g. Stripe, PayFast) are out of scope for municipal incident dispatch and introduce PCI-DSS compliance overhead.
IoT Hardware Sensor Ingestion Automated IoT telemetry (e.g. smart water meter telemetry or vibration sensors) requires edge brokers and time-series DB engines outside the relational ticket lifecycle scope.
Drag-and-Drop Form & Workflow Builders Building a generic no-code workflow creation tool would compromise relational integrity and performance. CivicConnect provides structured, indexed category parameters instead.
Third-Party ERP / CRM Synchronization Bidirectional synchronization with enterprise legacy systems (SAP, Salesforce) introduces tight coupling and distributed consensus overhead outside the municipal baseline.

2. Defense Against Scope Creep

Every excluded capability represents a conscious engineering decision. As documented in SEN381 Master Project Brief §18, every added capability incurs ongoing obligations across security audits, unit testing, schema migrations, documentation, and operational maintenance.
