2. Candidates Remaining Deferred (Post-M4 Roadmap)

The following features remain explicitly deferred for future operational phases:

  • External SMS / Push Notification Carrier Gateways: Integrating paid telecommunications carriers (e.g. Twilio, BulkSMS) would incur monthly consumption costs breaching the low-cost constraint (≤ $25/mo).
  • Photo & Attachment Storage: Attaching photographs of broken infrastructure requires object storage (e.g. AWS S3 / Azure Blob) and antivirus file-scanning pipelines, deferred to avoid cloud storage egress overhead.
  • GIS & Geographic Map Overlays: Interactive municipal map plotting (e.g. Mapbox / Google Maps API) for visual pothole clustering, deferred in favor of the hierarchical location catalogue (Site → Floor → Room).
  • Automated Citizen Feedback & CSAT Surveys: Post-resolution satisfaction scoring (1–5 stars) sent to citizens upon ticket closure.
  • Multi-Language / Localization: Translating the Blazor portal into additional official South African languages (isiZulu, Afrikaans, Sesotho).
